너는 시니어 프론트엔드 개발자다.
현재 프로젝트 구조를 먼저 확인한 뒤, 기존 코드 스타일과 컴포넌트 구조를 최대한 유지하면서 RELYN 태국 기업 임직원 대상 B2C 랜딩페이지를 구현해줘.

# 작업 목표

태국 기업 임직원을 대상으로 한국 미용시술 상담을 유도하는 B2C 랜딩페이지를 제작한다.

페이지 목적은 병원 직접 예약에 부담을 느끼는 태국 고객이 RELYN을 통해 먼저 LINE 또는 WhatsApp 상담을 남기도록 만드는 것이다.

# 중요 정책

1. 병원명, 병원 로고, 의료진명은 페이지 내에 노출하지 않는다.
2. 특정 병원을 추천하는 페이지처럼 보이지 않게 한다.
3. RELYN은 한국 미용시술 상담 및 예약 조율 파트너로 포지셔닝한다.
4. 상담 CTA는 페이지 중간 섹션마다 반복 배치하지 않는다.
5. 상담 CTA는 플로팅 버튼으로 상시 노출한다.
6. 본문 내 CTA는 최하단 CTA 섹션에만 1회 배치한다.
7. LINE 무료상담을 1순위 CTA로, WhatsApp 상담을 2순위 CTA로 구성한다.
8. 연예인 언급, 전후사진, 효과 보장성 표현은 사용하지 않는다.
9. 과장 표현, 최저가 보장, 부작용 없음, 100% 효과 같은 표현은 사용하지 않는다.
10. 최종 시술 가능 여부와 비용은 의료진 상담 및 병원 확인 후 결정된다는 주의 문구를 포함한다.

# Section 08. FAQ 영역

FAQ는 아코디언 형태로 구현해줘.

## Q1. 상담은 무료인가요?

네. LINE 또는 WhatsApp을 통한 1차 상담은 무료로 진행됩니다.

## Q2. 병원명을 먼저 알 수 없나요?

상담 전에는 병원명을 페이지에 노출하지 않습니다.
희망 시술, 일정, 예산, 고민 부위를 확인한 뒤
적합한 상담 방향을 안내드립니다.

## Q3. 어떤 정보를 보내면 되나요?

아래 정보를 보내주시면 상담이 더 빠르게 진행됩니다.

* 이름
* 방문 예정일
* 고민 부위
* 희망 시술
* 예산 범위

## Q4. 한국어를 못해도 괜찮나요?

네. 외국인 고객 상담을 고려하여 안내드립니다.

## Q5. LINE과 WhatsApp 상담 내용이 다른가요?

상담 내용은 동일합니다.
고객님이 더 편하게 사용하는 메신저를 선택해 문의하시면 됩니다.

## Q6. 상담 후 꼭 예약해야 하나요?

아닙니다.
상담 후 예약 진행 여부는 자유롭게 결정하실 수 있습니다.

## Q7. 회사에 상담 내용이 공유되나요?

개인 상담 내용은 개별 상담 기준으로 진행됩니다.
회사 제공 페이지를 통해 들어오더라도 상담 내용은 개인 문의로 취급됩니다.

# 구현 후 확인사항

작업 완료 후 아래 내용을 확인해줘.

1. 페이지가 정상 빌드되는지 확인
2. TypeScript 오류가 없는지 확인
3. Lint 오류가 없는지 확인
4. 모바일에서 하단 고정 CTA가 본문을 가리지 않는지 확인
5. Hero와 중간 섹션에 CTA 버튼이 들어가지 않았는지 확인
6. 최종 CTA 섹션에만 본문 CTA가 있는지 확인
7. 플로팅 CTA가 PC와 모바일에서 모두 정상 노출되는지 확인
8. LINE / WhatsApp 링크가 상수로 분리되어 추후 교체하기 쉬운지 확인
9. 병원명, 병원 로고, 의료진명 노출이 없는지 확인
10. 과장 표현, 전후사진, 효과 보장성 문구가 없는지 확인
11. SEO 메타 정보가 적용되었는지 확인
12. 기존 페이지나 공통 컴포넌트에 불필요한 영향이 없는지 확인
